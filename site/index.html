Drive Backup

A personal backup tool for Linux and Windows.

Drive Backup watches folders that the user chooses on their own computer. When a file in those folders is added or changed, it uploads that file to the user's own Google Drive, so important files are safe if the computer crashes or the disk fails.

  • Files go only to the signed-in user's own Google Drive, into a folder named Drive Backup.
  • It never deletes anything on Google Drive.
  • It uses the drive.file permission, so it can only see files it created itself, not the rest of your Drive.

This is a private, single-user app. It is not offered to the public.
